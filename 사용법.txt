HTML 편집 - 사용법

1. 압축을 푼 뒤 HTML편집.exe 를 더블클릭합니다.
   처음 한 번 "Windows의 PC 보호" 창이 뜨면 [추가 정보] -> [실행]을 누릅니다.
2. 브라우저에 시작 화면이 열리면 [열기]를 눌러 HTML 파일을 고릅니다.
   파일 선택 창이 안 보이면 작업 표시줄을 확인하세요 (브라우저 뒤에 뜰 때가 있습니다).
3. 고칠 글자를 클릭해서 바로 수정합니다.
   Enter = 줄바꿈, Ctrl+S = 원본 파일에 저장
   저장할 때마다 직전 버전이 "파일명.html.bak" 으로 같은 폴더에 남습니다.
4. 다 쓰면 화면 오른쪽 아래 [끄기]를 누릅니다.

알아둘 점
- Windows + Chrome/Edge 에서 동작합니다.
- 글자와 줄바꿈 전용입니다. 디자인이나 배치는 바꿀 수 없습니다.
- 자바스크립트가 내용을 그리는 HTML(움직이는 슬라이드 등)은 저장하지 마세요.
  화면에 그려진 결과가 파일에 굳어 버립니다.
